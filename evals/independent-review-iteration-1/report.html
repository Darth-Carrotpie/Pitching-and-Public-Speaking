Method and scope

  • Read all 45 files under the 22 outputs directories, including all companion speeches files and the HTML source. Did not open any existing grading.json or benchmark files. No repository or supplied output was edited.
  • Evaluated each of 46 expectations independently for both runs: 92 judgments. PASS requires the whole expectation, including compound clauses. Count independent answer requests rather than numbered bundles. A generic bracket is not the explicit NEEDS SOURCE marker.
  • Complete script means the primary version can be delivered without essential source-dependent blanks. Optional personalization and a complete safe alternative are acceptable. This causes both drafts in case 3 to fail completeness despite making substantial progress.
  • Scores in order: goal/message, story/visuals, call to action, accuracy, timing. Five is strong/complete; four has minor gaps; three is mixed or provisional; two has material defects; one fails fundamentally. In intake/gated/spar turns or where no speech slot was supplied, non-assessable dimensions receive a provisional 3, not fabricated full-performance credit. Story/visuals in non-create modes judges the supported guidance or framing, not an unnecessary story.
  • Averages are the unweighted means of all five requested scores. Winners are holistic: false factual premises can outweigh a formatting advantage (case 9); a delivered inspectable artifact breaks equal averages (case 5). This is one paired sample per prompt, not a stable estimate of general skill performance.
  • Timing uses 130 wpm and a 90% planned ceiling, counting only selected spoken text, not headings, directions, alternate openings or placeholder instructions. Source-dependent replacements are counted at their stated budgets. Explicitly prescribed pauses are added; short pauses and audience response can only increase that lower-bound estimate.
  • Tool histories were not supplied and cannot be reconstructed from present-day tools. Case 5.1 grades whether availability is plainly declared; it does not endorse the declaration. The no-tool fallback branch is not demonstrated in either run, so it receives no speculative conditional pass.
  • Unsupported is not a claim that a statement is false in the world. Clearly labelled hypotheticals, proposals, placeholders and supplied/validly derived numbers are distinguished from asserted user/company facts. External public claims were not independently fact-checked.

Source aliases within each run: R response.md; S script.md; BR brief.md; H rehearsal.md; L slides.md; N notes.md. Numbers are original line numbers. Source links below each case identify the exact files. Assertions of absence were checked against all output files, not just response.md.
