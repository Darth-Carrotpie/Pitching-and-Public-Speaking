# Checklist

**Create mode:** fix every item you can, silently. Hand over only what you couldn't
fix or what needs the user (a missing source, a choice only they can make).
**Review mode:** show the scorecard, each section pass or fix, one line each.

## Goal and message
- [ ] The goal is a verb: who does what, by when
- [ ] The one-line message passes at least 3 of the 4 tests (retell, headline, banner, 3 seconds)
- [ ] The message appears in the opening and again in the closing

## Arguments and audience
- [ ] At most 3 arguments, each about what the listener gets (island, not plane)
- [ ] No means or technical detail posing as an argument
- [ ] Each argument has proof or `[NEEDS SOURCE]`
- [ ] The elephant is named and parked (in the opening, an argument or the Q&A prep)
- [ ] The jargon level fits the audience (neighbour test)

## Structure and time
- [ ] Follows the agreed structure
- [ ] Opening about 15%, closing 10–15%
- [ ] Words ÷ 130 × 60 + timed pauses ≤ 0.9 × slot in seconds, with the sum shown in the script header
- [ ] "Just write it": the main script works aloud as is; personal details are optional inserts
- [ ] Skippable body beats are marked

## Opening
- [ ] The first sentence creates curiosity; no "hello, my name is…, thank you for having me"
- [ ] At most 2 questions
- [ ] 3 alternatives from different families, one recommended
- [ ] The first 3–5 sentences are marked `[MEMORIZE]`

## Body
- [ ] Every abstract claim has a concrete example
- [ ] At least one image, one emotional moment and one rhythm device
- [ ] Analogies are flagged for the outsider test

## Closing
- [ ] The summary repeats each argument as its 2–3 word tag
- [ ] The CTA is more concrete than the message: who, what, by when, the first step
- [ ] It doesn't end on "thank you" or "any questions?"
- [ ] A final close for after the Q&A, if there is Q&A

## Language (clarity filters)
- [ ] Person: a non-expert neighbour would follow it
- [ ] Active: verbs, first person, no "it is believed"
- [ ] Simple and short: everyday words, sentences mostly under 15 words, nothing that adds nothing

## Accuracy
- [ ] No invented facts, numbers, quotes, names or results
- [ ] No deduced facts: complements ("30% against"), durations, causes or logistics the user didn't give
- [ ] The brief, cue cards, rehearsal kit and Q&A prep checked too, not just the script
- [ ] Questions to the user: at most 6, counted by what they ask, not by numbering
- [ ] Every number has a source from the user, or `[NEEDS SOURCE]`
- [ ] Numbers are rounded and made concrete

## Slides (if any)
- [ ] One idea per slide, an assertion headline, visual evidence
- [ ] About 6 words at most besides the headline; no script on the slides
- [ ] Every slide maps to a script line and a `[SLIDE n]` cue
- [ ] Leave-behind lines are there, if a leave-behind was requested
- [ ] Slide tools reported with their level and how you checked; with no callable tool, `slides.marp.md` is written

## Rehearsal kit
- [ ] The timing table fits the slot
- [ ] The top 3 techniques are chosen for this speaker, not generic
- [ ] The Q&A prep includes the elephant and the hardest question
