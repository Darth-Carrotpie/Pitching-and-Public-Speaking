# Feedback Is a Developer Skill: cue cards

## Card 1: Opening [0:00] [SLIDE 1]

(word for word)
> “Picture this. You open a pull request and see a comment: ‘This is wrong.’”
> “Your code is unchanged, but your pulse is not. You cannot tell what is wrong, how serious it is, or what comes next.”
> “We spend years learning code. When it meets another human, another skill takes over.”
> “Feedback is a core developer skill, not a soft extra.”

## Card 2: Clear reasoning [0:37] [SLIDE 2]

- PR = feedback conversation
- bad: “This is wrong” hides reasoning
- better: retry risk → loop forever? → cap?
- risk · reason · route
→ “Clear feedback replaces guessing with a next step.”

## Card 3: Shared problem [1:23] [SLIDE 3]

- specific + useful + human
- notice → effect → next step
- several files / hard to verify / together or map?
- no verdict; something to examine
- other settings `(skip if late)`

## Card 4: Deliberate practice [2:22] [SLIDE 4]

- tense chat box; blinking cursor
- ask: target, not “Thoughts?”
- give: observation, not label
- receive: “What did you notice?”
→ next time: pause · notice · next step

## Card 5: Shared debugging [3:18] [SLIDE 5]

- concern clear; author knows why
- disagreement is allowed
- trade-off, not tone
- not you vs me
→ both vs problem
